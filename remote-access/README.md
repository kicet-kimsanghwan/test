# Remote Access (화면 공유 + 원격 제어)

서로 다른 네트워크(IP)에 있는 두 컴퓨터 중 한쪽(host)의 화면을 다른 쪽(client)에서
보면서 마우스/키보드로 직접 제어할 수 있는 간단한 원격 데스크톱 도구입니다.

> ⚠️ **본인 소유이거나 명시적으로 제어 권한을 받은 컴퓨터에만 사용하세요.** 이 도구는
> 상대 컴퓨터의 화면을 실시간으로 전송하고 입력을 그대로 주입합니다. 동의 없이 다른
> 사람의 컴퓨터에 설치·연결하는 것은 불법입니다.

## 구조

```
remote-access/
  remote_access/
    protocol.py      길이 프리픽스 기반 메시지 프레이밍 (TLS 소켓 위에서 동작)
    crypto_utils.py   자체서명 TLS 인증서 생성 + TOFU 방식 인증서 핀닝
    host.py           제어당하는 쪽(에이전트): 화면 캡처 → 전송, 입력 이벤트 수신 → 주입
    client.py         제어하는 쪽(뷰어): Tkinter 화면 표시, 마우스/키보드 이벤트 전송
  run_host.py         host.py 실행 진입점
  run_client.py       client.py 실행 진입점
  requirements.txt
```

## 설치

두 컴퓨터 모두에 Python 3.9+ 와 의존성이 필요합니다.

```bash
cd remote-access
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 사용법

### 1. 제어당할(호스트) 컴퓨터에서

```bash
python run_host.py --port 5900
```

- 실행하면 비밀번호를 입력하라는 프롬프트가 뜹니다 (`--password` 또는
  `REMOTE_ACCESS_PASSWORD` 환경변수로도 지정 가능).
- 콘솔에 인증서 지문(fingerprint)이 출력됩니다. 클라이언트 쪽 사용자와 안전한 채널
  (전화, 메신저 등)로 이 값을 미리 공유해두면, 클라이언트에서 `--fingerprint` 옵션으로
  중간자 공격 여부를 검증할 수 있습니다.
- **다른 네트워크(IP)에 있는 컴퓨터**에서 접속하려면, 이 컴퓨터가 붙어 있는
  공유기(라우터)에서 지정한 포트(예: 5900)를 이 컴퓨터의 내부 IP로 포트포워딩해야
  합니다. (공유기 관리 페이지 → 포트포워딩/가상서버 설정)

### 2. 제어할(클라이언트) 컴퓨터에서

```bash
python run_client.py <호스트의 공인 IP 또는 도메인> --port 5900
```

- 같은 비밀번호를 입력하면 인증 후 호스트 화면이 새 창에 표시됩니다.
- 창 안에서 마우스를 움직이거나 클릭/스크롤/키보드 입력을 하면 그대로 호스트에
  전달됩니다.
- 처음 접속하는 호스트는 인증서 지문을 자동으로 신뢰(TOFU)하고
  `~/.remote_access/trusted_hosts.json`에 저장합니다. 이후 같은 주소의 지문이
  바뀌면(예: 다른 사람이 가로채는 경우) 연결을 거부하고 경고를 출력합니다.

## 보안 모델

- **전송 구간**: 자체서명 TLS로 전체 트래픽(화면 프레임 + 입력 이벤트)을 암호화합니다.
- **인증**: 비밀번호 자체는 네트워크로 전송되지 않고, 호스트가 보낸 난수(nonce)에 대한
  HMAC-SHA256 값만 주고받는 챌린지-리스폰스 방식입니다.
- **중간자 공격 방지**: TOFU 인증서 핀닝. 더 엄격하게 하려면 호스트 실행 시 출력되는
  지문을 클라이언트 실행 시 `--fingerprint`로 명시하세요.
- 이 정도 구현은 개인/소규모 용도에 적합한 수준이며, 상용 배포용으로는 별도의 보안
  감사와 속도 제한(brute-force 방지), 세션 타임아웃 등을 추가로 고려해야 합니다.

## 옵션

**host.py**
| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--port` | 5900 | 대기 포트 |
| `--bind` | 0.0.0.0 | 바인드 주소 |
| `--monitor` | 1 | mss 모니터 인덱스 (다중 모니터 시 조정) |
| `--fps` | 15 | 화면 전송 프레임레이트 |
| `--quality` | 60 | JPEG 압축 품질 (1-95, 낮을수록 대역폭 절약) |
| `--password` | (프롬프트) | 세션 비밀번호 |

**client.py**
| 옵션 | 기본값 | 설명 |
|---|---|---|
| `host` | (필수) | 접속할 호스트 IP/도메인 |
| `--port` | 5900 | 호스트 포트 |
| `--password` | (프롬프트) | 세션 비밀번호 |
| `--fingerprint` | 없음 | 기대하는 인증서 지문 (지정 시 TOFU 자동신뢰 대신 이 값과 대조) |

## 알려진 제한사항

- 화면은 볼 수 있지만 클립보드 동기화, 파일 전송, 다중 모니터 동시 전송은 아직
  지원하지 않습니다.
- macOS/일부 리눅스 배포판에서는 화면 캡처·입력 주입에 접근성(Accessibility) 권한
  허용이 필요할 수 있습니다.
- 방화벽/NAT 환경에서는 포트포워딩이 필수입니다 (중계 서버를 두는 방식이 아님).
